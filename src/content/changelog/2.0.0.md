### Added

- A **/work** section: a running career changelog on a vertical timeline
  rail, led by a Selected Work list of case studies and freelance projects.
- **/colophon** documenting how the site is built.
- **/changelog** — this page — tracking the site as it evolves.
- A markdown pipeline on Sätteri + Shiki: code blocks get window chrome, a
  filename tab when the fence sets `title=`, and a hover-revealed copy
  button with dual catppuccin light/dark themes.

### Changed

- Reworked the home page as bio-as-prose — inline links, no hero, cards, or
  grid — inside a single narrow reading column.
- Simplified the nav to one wrapping line of text links with a plain
  light/dark toggle.
- Moved fonts (Geist, Geist Mono, Reenie Beanie) to the Astro Fonts API.

### Removed

- The old hero, polaroids, and card-based home components.
- `astro-expressive-code`, `rehype-autolink-headings`, and the
  remark/rehype markdown stack, replaced by the Sätteri pipeline.
- Locally bundled `.woff2` font files.
